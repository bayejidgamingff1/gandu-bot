#🐐 Goat Bot v2.5

Private Messenger Bot by Bayejid

A feature-packed Messenger Bot built with Node.js, designed to run seamlessly on your personal Facebook account. Lightweight, fast, and highly customizable for an enhanced messaging experience.


---

✨ Key Features

🚀 Auto-Restart & Crash Recovery – Keeps your bot running 24/7

🛠 Command System – Easy-to-use, modular, and extendable

🔒 Role-Based Permissions – Admin and user controls for secure operation

⚡ Lightweight & Fast – Optimized for Node.js v20

📝 Configurable Setup – Quick setup via config.json

🌐 Multi-Language Support – Communicate in multiple languages

🍪 Account Cookies Support – Add cookies directly in Account.txt

🎀 Deployment Ready – Recommended deployment on Render.com



---

Stable & reliable, even during crashes or downtime

Friendly for both beginners and advanced users



---

⚡ Quick Start

1. Clone the repository

git clone https://github.com/bayejidgamingff1/gandu-bot.git


2. Install dependencies

npm install


3. Configure your bot in config.json


4. Add account cookies in Account.txt


5. Run the bot

node index.js
